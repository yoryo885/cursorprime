# Skill: Social proof

## Regla
Justo bajo el hero: una cifra creíble o logos/nombres que den confianza.
Una línea. No inventar métricas sin fuente.

## Obligatorio
- Una cifra O lista corta de logos/marcas (máx. 5).
- Texto de apoyo ≤ 12 palabras.
- Si no hay datos reales: marcar `"confianza": "baja"` y usar claim cualitativo.

## Ejemplo
"6 guías · 5 oficios · PDF listo para aplicar"

## Output esperado (JSON)
{ "cifra_o_logos": "", "texto": "", "confianza": "alta|media|baja" }
