# Skill: Footer

## Regla
Contacto + redes + legales. Compacto. Sin copy de venta.

## Obligatorio
- Marca / copyright.
- Email o contacto (placeholder OK si falta).
- Links legales: privacidad, términos (pueden ser #).
- Redes opcionales (lista corta).

## Ejemplo
"Vértice Pro · hola@vertice.pro · Privacidad · Términos"

## Output esperado (JSON)
{ "marca": "", "contacto": "", "legales": ["Privacidad", "Términos"], "redes": [] }
