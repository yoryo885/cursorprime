# Skill: Benefits

## Regla
3 a 5 beneficios: resultado para el usuario, no feature técnica.
Cada ítem = verbo + resultado medible o palpable.

## Obligatorio
- Entre 3 y 5 items.
- Título corto + texto de 1 frase.
- Sin "potente", "innovador", "única solución".

## Ejemplo
"Plan de 10 semanas" · "Sabés qué hacer cada semana, sin relleno."

## Output esperado (JSON)
{ "items": [ { "titulo": "", "texto": "" } ] }
