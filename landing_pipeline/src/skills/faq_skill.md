# Skill: FAQ

## Regla
4 a 6 preguntas que eliminan la última objeción antes de pagar.
Una DEBE cubrir garantía / devolución / riesgo.

## Obligatorio
- Entre 4 y 6 pares q/a.
- Cubrir: qué es, para quién, entrega, diferencia, **garantía/riesgo**, precio.
- Solo `nombre_producto` / `propuesta_valor` (nunca nombres internos).
- Respuestas ≤ 40 palabras.

## Ejemplo
"¿Qué pasa si no me sirve?" · "Escribinos y te ayudamos — sin letra chica."

## Output esperado (JSON)
{ "items": [ { "q": "", "a": "" } ] }
