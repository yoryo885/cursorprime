# Skill: FAQ

## Regla
4 a 6 preguntas que eliminan la última objeción antes de pagar.
Respuestas cortas, concretas, sin rodeos.

## Obligatorio
- Entre 4 y 6 pares q/a.
- Cubrir: qué es, para quién, entrega, diferencia, precio.
- Respuestas ≤ 40 palabras.
- Usar únicamente `nombre_producto` y `propuesta_valor` del brief en texto visible.
  Nunca nombres internos de catálogo/dataset (ej. "Guías PDF libro × rol" si el producto público es "Vértice Pro").

## Ejemplo
"¿Qué es Vértice Pro?" · "Guías prácticas para tu oficio, sin relleno."

## Output esperado (JSON)
{ "items": [ { "q": "", "a": "" } ] }
