# Skill: FAQ

## Regla
4 a 6 preguntas que eliminan la última objeción antes de pagar.
Respuestas cortas, concretas, sin rodeos.

## Obligatorio
- Entre 4 y 6 pares q/a.
- Cubrir: qué es, para quién, entrega, diferencia, garantía/devolución si aplica.
- Respuestas ≤ 40 palabras.

## Ejemplo
"¿Es un resumen genérico?" · "No: cada guía está escrita para un rol concreto."

## Output esperado (JSON)
{ "items": [ { "q": "", "a": "" } ] }
