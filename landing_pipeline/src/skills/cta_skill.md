# Skill: CTA final

## Regla
Repite la oferta del hero, notorio y directo.
Misma promesa, mismo CTA (o variante mínima).

## Obligatorio
- Headline que echo el hero.
- Sub ≤ 1 frase.
- Botón = verbo + resultado.

## Ejemplo
"Elegí tu guía y empezá esta semana" · [Ver colección]

## Output esperado (JSON)
{ "headline": "", "sub": "", "cta": "" }
