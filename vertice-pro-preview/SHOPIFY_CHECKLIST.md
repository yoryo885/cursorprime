# Checklist Shopify — Vértice Pro (para cuando despiertes)

## Ya listo en el repo

| Archivo | Uso en Shopify |
|---------|----------------|
| `assets/hero-lifestyle.jpg` | Imagen hero / banner (~80 KB, optimizada) |
| `assets/og-image.jpg` | Compartir en redes (1200×630) |
| `assets/favicon.png` | Favicon |
| `assets/portada-pareto.png` | Foto del producto PDF |
| `tienda.html` | Referencia visual (copiar estructura al theme) |

## Tú haces en Shopify (necesita tu cuenta)

1. [ ] Abrir admin Shopify → **Online Store → Themes**
2. [ ] Subir hero: `hero-lifestyle.jpg` (o pegar URL de la imagen)
3. [ ] Crear producto: **Pareto para psicopedagogas en 10 semanas**
4. [ ] Subir PDF como archivo digital (o app de entrega digital)
5. [ ] Subir `portada-pareto.png` como imagen del producto
6. [ ] Precio: confirmar ($4.99 u otro)
7. [ ] Activar pagos (Webpay / Mercado Pago / Shopify Payments)
8. [ ] Dominio o `*.myshopify.com`
9. [ ] Probar compra de prueba

## No hacer aún (acordado)

- Dropshipping de repisas / físicos  
- Videos de tráfico  
- Más roles sin vender el primero  

## Si algo falla

Abre el preview local: `http://localhost:8768/tienda.html`  
o el HTML online del PR.
