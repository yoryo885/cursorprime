# Branding del informe (logo + WhatsApp)

Edita `marketing-audit/meta/report_branding.json`:

```json
{
  "nombre": "Tu Agencia",
  "whatsapp": "56912345678",
  "whatsapp_mensaje": "Hola, vi el informe de marketing y quiero la llamada.",
  "email": "tu@email.cl",
  "logo": "assets/logo.svg"
}
```

**Logo:** reemplaza `assets/logo.svg` por tu PNG/SVG (recomendado ~160×48 px).

El HTML copia el logo junto al informe para que se vea al abrirlo o enviarlo.
