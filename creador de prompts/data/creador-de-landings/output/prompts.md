# Prompt — Creador de Landings

```
Usa el proyecto creador-de-landings.

REGLA:
Cada idea de tienda/landing → entrevista estándar con opciones A B C D.
Usuario responde solo letras (ej. 1A 2A 3B… o "todo A").
No pedir texto libre salvo opción D.

Fuente: meta/preguntas.json
CLI:
  python3 landings_main.py preguntas
  python3 landings_main.py responder --slug {slug} --letras "1A 2A 3A…" --generar
```
