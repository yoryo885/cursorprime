# Prompt — Creador de Landings

```
Usa el proyecto creador-de-landings.

1. Corre entrevista (o demo como cliente).
2. Muestra 3 estilos: editorial | mockup | oferta.
3. Genera data/{slug}/output/preview.html.
4. No inventes testimonios reales.

CLI:
  python3 landings_main.py demo
  python3 landings_main.py entrevista --slug {slug}
  python3 landings_main.py generar --slug {slug} --ejemplo editorial
```
