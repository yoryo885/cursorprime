# Hooks Redes

Skill de **capacidad** — ganchos para video corto y redes.

## Objetivo

3 ganchos por brief, listos para grabar o pasar a `guion-a-video`. Inspirado en sistemas de content OS (hook → script → video → caption).

## Cuándo usar

Triggers: hook, gancho, primeras líneas, usa hooks-redes, reels, shorts, tiktok.

## Formato de entrega

Por cada variante:

```
HOOK: (≤15 palabras, 1-2 líneas)
ÁNGULO: qué promete el video
CTA: comenta / guarda / sigue
TIPO: curiosidad | contrarian | historia
```

## Criterios de calidad

- **3 variantes** mínimo: curiosidad, contrarian, historia personal.
- **≤15 palabras** en el hook principal — debe funcionar en voz en off o texto en pantalla.
- **Promesa concreta** — no clickbait vacío ("esto cambió todo" sin decir qué).
- Español LATAM natural; tono según brief (profesional, directo, Yordy, etc.).
- Si hay guion existente, el hook debe alinearse al contenido real.

## Ejemplos de estructura

| Tipo | Patrón |
|------|--------|
| Curiosidad | "Nadie te dice que [X] funciona porque…" |
| Contrarian | "Dejé de [práctica común]. Resultado: …" |
| Historia | "Hace [tiempo], [evento concreto]. Aprendí…" |

## Encadenar

```
hooks-redes → guion/script → guion-a-video → captions-redes → thumbnail-social
```
