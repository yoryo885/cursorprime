# Skill: CTA

## Regla
Una sola acción concreta (comentar, guardar o seguir), nunca las tres a la vez.

## Obligatorio
- Una sola CTA.
- Acción concreta y fácil ("comenta X", "guarda esto").
- Colocada cerca del final, no apurada en 0.5 s.

## Ejemplo
"Comenta PARETO y te paso el checklist"

## Output esperado (JSON)
{ "cta": "", "accion": "comentar|guardar|seguir", "palabra_clave": "" }
