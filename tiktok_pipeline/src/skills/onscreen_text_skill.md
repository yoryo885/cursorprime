# Skill: Texto en pantalla

## Regla
Palabra o frase clave por escena, sincronizada con lo que se dice, pensado para verse sin sonido.

## Obligatorio
- Una frase corta por bloque (máx. 6 palabras).
- Legible en móvil (sin párrafos).
- Refuerza lo dicho, no lo duplica literal si es largo.

## Ejemplo
Pantalla: "20% que importa" mientras se explica Pareto.

## Output esperado (JSON)
{ "textos": [{"escena_id": 1, "texto": "", "t_inicio": 0, "t_fin": 3}] }
