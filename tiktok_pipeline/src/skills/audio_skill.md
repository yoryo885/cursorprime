# Skill: Audio

## Regla
Sugiere tipo de sonido (trend, voz en off, música de fondo) según el ritmo del guion, no un archivo específico.

## Obligatorio
- Tipo: trend | voz_off | musica_fondo | mix.
- BPM/ritmo sugerido (lento / medio / rápido).
- Nota de por qué encaja con el guion.

## Ejemplo
voz_off + música de fondo suave, ritmo medio.

## Output esperado (JSON)
{ "tipo": "voz_off", "ritmo": "medio", "nota": "", "sugerencia_busqueda": "" }
