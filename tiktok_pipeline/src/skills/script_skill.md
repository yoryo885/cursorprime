# Skill: Script

## Regla
Un solo mensaje central, no tres temas mezclados. Estructura tipo paso 1 / paso 2 / paso 3 o historia con giro.

## Obligatorio
- Un mensaje central claro.
- 3 bloques de desarrollo (paso o escena).
- Lenguaje hablado, frases cortas, español LATAM.
- Total ~25–45 segundos de habla.

## Ejemplo
Mensaje: "El 20% de tus tareas genera el 80% del resultado."
Bloques: identificar / cortar lo inútil / proteger el 20%.

## Output esperado (JSON)
{ "mensaje_central": "", "bloques": [{"id": 1, "texto": ""}, {"id": 2, "texto": ""}, {"id": 3, "texto": ""}], "duracion_seg_aprox": 35 }
