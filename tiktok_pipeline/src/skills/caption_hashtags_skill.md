# Skill: Caption + Hashtags

## Regla
El caption refuerza el hook sin repetirlo, 3 a 5 hashtags de nicho, no genéricos tipo #viral o #fyp.

## Obligatorio
- Caption 1–3 líneas.
- 3–5 hashtags de nicho (nada de #fyp #viral #parati).
- CTA suave opcional al final del caption.

## Ejemplo
Caption: "El truco no es hacer más. Es soltar el 80%."
Tags: #pareto #productividad #enfoque

## Output esperado (JSON)
{ "caption": "", "hashtags": ["", "", ""] }
