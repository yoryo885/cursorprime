# Skill: Loop

## Regla
La última frase debe conectar con la primera para que el video se repita solo.

## Obligatorio
- Última línea engancha con el hook.
- Sensación de ciclo (pregunta abierta o eco del inicio).
- Sin "gracias por ver".

## Ejemplo
Hook: "Nadie te dice esto sobre ahorrar" → Loop: "Y eso… nadie te lo dice."

## Output esperado (JSON)
{ "loop": "", "conexion_con_hook": "" }
