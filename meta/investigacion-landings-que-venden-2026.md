## 2. Cómo se ven las que más convierten (look 2026)

Patrón visual que se repite en landings de alto rendimiento:

1. **Una sola idea en la primera pantalla**  
   Marca + promesa + 1 botón. Sin relleno (stats, horarios, muchas cajas).

2. **Imagen grande real o mockup del producto**  
   Para PDF/ebook: mockup en tablet/escritorio o lifestyle (como tu imagen 6). No collage de 5 fotos peleando.

3. **Poco menú**  
   Menos distracciones = más compras. En tráfico pago a veces ocultan el menú.

4. **Prueba social cerca del botón**  
   Estrellas, reseñas cortas, “X descargas”, logos — **junto** al CTA, no escondidas abajo.

5. **Bloques con un solo trabajo cada uno**  
   Qué incluye → para quién → preview → reseñas → FAQ → comprar otra vez.

6. **Móvil primero**  
   Botón grande, texto corto, carga rápida. La mayoría del tráfico llega por celular.

**No es el look “más moderno”.** Es el look **más claro**.

## 3. Números reales 2025–2026 (para evaluar)

### A) Landing genérica (lead / registro / click CTA)

| Nivel | Conversión aprox. | Fuente |
|-------|-------------------|--------|
| Mediana | ~**6.6%** | Unbounce Q4 2024 (41k landings) |
| “Buena” | **≥10%** | Unbounce |
| Top | **11%+** | Cuartil alto Unbounce |

*(Aquí “conversión” = la acción de la página: formulario, click, etc., no siempre compra.)*

### B) Tienda Shopify / ecommerce (compra)

| Nivel | Conversión de compra | Fuente |
|-------|----------------------|--------|
| Típico DTC | **1.5% – 3.5%** | Karbon Shopify 2026 |
| Promedio mercado | ~**1.7% – 2.7%** | Landra / IRP / Triple Whale 2026 |
| Fuerte | **≥3%** | Blend Commerce 2026 |
| Excelente / top | **≥4.7%** (top 10% Shopify) | Triple Whale feb 2026 |

### C) Según de dónde viene la gente

| Tráfico | Conversión típica |
|---------|-------------------|
| Email / clientes | alta (a menudo 5–9%) |
| Búsqueda de marca | alta |
| Ads fríos (Meta/TikTok) | baja (a veces **&lt;1%**) |
| Landing dedicada vs PDP cruda | landing suele ganar |

**Importante:** una landing “que factura mucho” casi siempre tiene **mucho tráfico bueno**, no solo un diseño lindo. Ingreso ≈ visitas × conversión × ticket.

## 4. Cómo se evalúa una buena landing (checklist profesional)

Marca cada punto:

### Primera pantalla (above the fold)
- [ ] Se entiende la oferta en **&lt;5 segundos**
- [ ] Hay **un solo CTA** claro
- [ ] La imagen refuerza el producto (no es decoración suelta)
- [ ] La marca se nota sin quitar el menú
- [ ] Carga en **&lt;3 s** en móvil (ideal &lt;2 s)

### Oferta
- [ ] Headline = **resultado** (“prioriza casos en 10 semanas”), no solo “PDF”
- [ ] Para quién es / para quién no
- [ ] Qué incluye (páginas, formato, entrega)

### Confianza
- [ ] Reseñas o prueba social cerca del botón
- [ ] Política clara (digital: descarga al instante, reembolso si aplica)
- [ ] FAQ de las 5 dudas típicas

### Producto digital (PDF / ebook) — extra 2026
- [ ] Mockup o preview de páginas
- [ ] “Descarga inmediata” visible
- [ ] Formato / tamaño / licencia
- [ ] Entrega automática probada (pedido de prueba)

### Métricas (después de publicar)
| Métrica | Para qué |
|---------|----------|
| Visitas | ¿llega gente? |
| % scroll / tiempo | ¿leen? |
| Clics en CTA / add to cart | ¿quieren comprar? |
| Checkout → compra | ¿el pago frena? |
| Conversión = compras / visitas | nota final |
| Ingreso = conversión × precio × visitas | lo que importa al negocio |

## 5. Estructura de las landings que más venden (orden)

```
1. Hero: promesa + imagen + CTA
2. Problema (1–2 frases)
3. Qué incluye / beneficios
4. Preview / demo
5. Prueba social
6. FAQ (objeciones)
7. CTA final
```

Una acción sola: **comprar / descargar**.

---

## 6. Qué hace que “reciban muchos ingresos”

No es magia del HTML. Las tiendas que facturan alto suelen tener:

1. Tráfico constante (ads, orgánico, email, Pinterest…)  
2. Oferta clara a un nicho  
3. Landing/PDP que no frena  
4. Precio + ticket (bundles suben ingreso)  
5. Recompra / lista de email  

**Diseño solo** no genera “hartos ingresos”. Diseño + tráfico + oferta sí.

## 7. Tu landing Vértice Pro — diagnóstico rápido

| Criterio 2026 | Estado actual |
|---------------|---------------|
| Hero claro + 1 imagen | Bien (imagen 6) |
| Marca fuerte en primera pantalla | Bien |
| 1 CTA arriba | Bien |
| Velocidad (JPG ~80 KB) | Bien encaminado |
| Preview del PDF / páginas internas | **Falta** |
| “Qué incluye” detallado | Débil |
| Reseñas cerca del botón de compra | Mejorable |
| FAQ digital | **Falta** |
| Checkout real Shopify | Pendiente de ti |

**Veredicto para venta:** buena **base visual**. Aún no es una landing “de alto ingreso” hasta: preview + FAQ + compra real + tráfico.
